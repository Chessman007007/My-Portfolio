#  Portfolio

A responsive personal portfolio made with plain HTML, CSS, and vanilla JavaScript. No framework, build step, backend, or package installation is required.

## Run the website

1. Extract the ZIP file.
2. Open the `purple-portfolio` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension if available.

## Folder structure

```text
purple-portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── README.md
```

## Features

- Responsive navigation with an accessible mobile menu
- About and skills sections
- Project cards rendered from a JavaScript array
- Category filters: All, Websites, JavaScript Apps
- Light/dark theme with guarded `localStorage` persistence
- Contact form validation, field errors, first-invalid-field focus, and live character count
- Accessible status message for the demo form
- Keyboard focus indicators and reduced-motion support

## Personalize before submitting

- Replace `Your Name` and `yourname` in `index.html`.
- Update the bio, skills, contact email, and profile links.
- Replace the sample projects in `js/main.js` with at least four real projects, their actual technologies, and working repository/demo URLs.
- Update the page title and meta description.
- Add credits if you use external assets.

## Contact form limitation

The form is frontend-only. It does not send, save, or transmit messages. A valid submission displays: `Demo only. Your message has not been sent.` Visitors can use the `mailto:` link as an alternative.

## Test checklist

- Test at widths around 360px, 768px, and 1280px.
- Open and close the mobile menu; use Escape and a keyboard.
- Test every category filter and confirm the visible project count.
- Toggle the theme, reload, and verify the saved theme.
- Try a one-character name, invalid email, and message shorter than 20 characters.
- Submit valid fields and confirm the demo-only message appears without a reload.
- Replace all placeholder links before submitting.
